## 2. ATC Contract

```typescript
/**
 * ATC: Owner removes a Member from the Members screen and confirms.
 * Fixed assertions:
 *  - the Remove control for the target exists on the row (accessible name `Remove <email>`)

 *  - after confirming, the target row is gone
 */
```

## 3B. UI Details

- Page path: `/workspaces/{workspaceId}/members` (`goto` is a helper, outside the ATC, as in `ui-auth.setup.ts`).
- Locators inline (confirm with `/playwright-cli` snapshot first, O6): Remove button by role + name `Remove <email>`; `getByRole('alertdialog')`; confirm button inside the dialog.
- Wait on a condition: `expect(row).toBeHidden()` or the DELETE `waitForResponse` (status 200), never a fixed timeout. The dialog stays open on 5xx, so assert it closes.
