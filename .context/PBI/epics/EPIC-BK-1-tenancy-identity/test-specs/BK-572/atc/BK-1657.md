- The confirming roster GET stays INSIDE the ATC (Rule 7).

## 4. Assertions Split

### Fixed (inside ATC)
200, response keys, `removed_user_id`, roster no longer lists the target.

### Test-level (in test file)
`revoked_token_count` = 1, `unassigned_bug_count` = 3 (`revoked_invite_count` = 0); scoped PAT -> 401 "Invalid token"; global PAT -> 200 on `GET /v1/workspaces`, second workspace present, fixture workspace absent; 3 held Bugs `assignee_user_id` null (`BugApi.getBug`); exactly 3 new `bug.unassigned` feed items, one per Bug, and exactly 1 new `member.removed` item with the caller as actor (delta against the pre-call page, ids from `payload`); Owner and Member notification inbox sizes unchanged; authored Bug still readable with `created_by` = Member.
