# ATC Spec: BK-1665 — removeMemberRefusedBelowAdmin

> Ticket: BK-1665 (TC15)
> Component: WorkspaceApi (tests/components/api/WorkspaceApi.ts), EXTEND
> Type: API — Negative (ladder, parameterized)
> Parent Story: BK-572 (AC-03, divergence 4)

## 1. Test Case Summary

| Name | Objective | Precondition | Acceptance Criteria |
|------|-----------|--------------|---------------------|
| should refuse with 403 not_a_member for any target, including themselves, when a Member or a Viewer calls the endpoint | Callers below Admin are refused for every target; self-target is 403 not 409 (caller role check runs before the self check) | Four active members; caller (Member or Viewer) signed in | AC-03, divergence 4 |

## 2. ATC Contract

```typescript
/**
 * ATC: a caller below Admin attempts a removal.
 * Fixed assertions:
 *  - status 403
 *  - body.error.details.reason === 'not_a_member' (NOT 'missing_capability', NOT 409 cannot_remove_self)
 *  - roster size and roles unchanged
 */
@atc('BK-1665')
async removeMemberRefusedBelowAdmin(args: { workspaceId: string, targetUserId: string }):
  Promise<[APIResponse, ErrorEnvelope]>
```

## 3A. API Details

- `DELETE /v1/workspaces/{workspaceId}/members/{targetUserId}` with the caller's cookie session context (Member or Viewer; neither can mint a `workspace:admin` PAT, so cookie is the only possible credential for these rows).
- Through the direct RPC the refusal is SQLSTATE 42501 (not HTTP; out of scope).

## 4. Assertions Split

### Fixed (inside ATC)
403, `details.reason` `not_a_member`, roster unchanged.

### Test-level (in test file)
No `member.removed` item newer than the baseline; target ids resolved from the roster (self rows use the caller's own id).
