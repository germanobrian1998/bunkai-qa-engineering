## 1. Test Case Summary

| Name | Objective | Precondition | Acceptance Criteria |

## 2. ATC Contract

 * ATC: Admin attempts to remove the Owner.

 *  - status 403

@atc('BK-1664')
async removeOwnerAsAdminRefused(args: { workspaceId: string, ownerUserId: string }):
  Promise<[APIResponse, ErrorEnvelope]>

## 3A. API Details

- `DELETE /v1/workspaces/{workspaceId}/members/{ownerUserId}` with the Admin cookie session context (no Bearer).
- Why the cookie matters: an `api:login` PAT has no `workspace:admin`, so the call would answer 403 `missing_capability` before the ladder runs. The reason assertion makes that mistake fail loudly instead of passing vacuously.
- Through the direct RPC the same refusal is errcode 45221 (not observable on HTTP; out of scope).

## 4. Assertions Split

### Fixed (inside ATC)
403, `details.reason` `cannot_remove_owner`, Owner still on the roster.

### Test-level (in test file)
Roster identical to the pre-call baseline (4 members, same roles); activity feed has no `member.removed` item newer than the baseline.
