# ATC Spec: BK-2163 - A viewer cannot rename, archive or restore

> Ticket: BK-2163 (TC24)
> Component: TestsApi (tests/components/api/TestsApi.ts), NEW
> Type: API - Negative
> Parent Story: BK-596

## 1. Test Case Summary
| Name | Objective | Precondition | Acceptance Criteria |
|------|-----------|--------------|---------------------|
| should offer a workspace viewer no rename, archive or restore control and refuse each call with 403 given a live or archived Test | Only someone who can change the Test can act | Viewer holds the viewer role in the workspace; Test live, or archived by the member first for the restore row | AC-08 8.1 |

## 2. ATC Contract
```typescript
@atc('BK-2163')
async refuseWriteByViewer(args: { testId: string, action: 'rename' | 'archive' | 'restore' }): Promise<[APIResponse, ErrorEnvelope]> {
  const [response, body] = await this.sendViewerWrite(args);
  expect(response.status()).toBe(403);
  expect(body.error.code).toBe('forbidden');
  return [response, body];
}
```
Called on the Viewer's `ApiFixture` (cookie session of the viewer role). The reason text (`not_a_member`) is a known shared mapping (BK-2091), so only `error.code` is asserted.

## 3A. API Details
`PATCH`, `DELETE /api/v1/tests/{id}` and `POST /api/v1/tests/{id}/restore`; 403 `forbidden`.

## 4. Assertions Split
### Fixed (inside ATC)
403 and `forbidden`.
### Test-level (in test file)
The Test is unchanged when read by the Member (`getTest`: title, version, archived state); no new activity event; the Viewer's browser context shows no rename, archive or restore control (`TestDetailPage.expectNoWriteControls`); the Member restores the Test archived for the restore row.
